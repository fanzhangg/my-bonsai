# 修叶玩法 · 本轮实现

连续拖动只是一种操作方式。修叶剪根据叶片位置落刀，剪下完整叶片或针叶小束，不再沿指针轨迹擦除像素。

## 选择与界面

选择同一层的大树冠，不按小叶团拆分。同层叶团、枝梢叶片及初生小叶都可参与修剪。选中后整层前置、保持原色，其他枝叶与盆器淡灰显示；保持原来的整树取景。

修叶剪是独立工具，与剪枝使用一致的场景交互。界面只保留树、层级提示点和剪刀，无撤销、换团、完成按钮及常驻说明。

## 落刀逻辑

1. 点击修叶剪，选择整层树冠；或直接拖动剪刀靠近树冠。
2. 刀尖显示空心十字准星和细小中心点，中心与实际落刀坐标重合，不遮挡要剪的叶片。不高亮待剪叶片，按下立即剪下一片完整叶片或一束针叶，无停留确认和倒计时。按住移动可继续修剪，每次合剪至少间隔 170ms；停住或松手不追加剪切。命中检测共用渲染叶形，包含旋转后的边缘、针叶尖和新叶尺寸；正中叶片优先于附近叶片，实际重叠时剪最上面的叶片。
3. 优先剪到表层的叶片，露出下层后再继续修剪，不会一笔贯穿所有重叠叶团。
4. 剪落叶片保持原有形状和颜色，短暂下落；没有碰到叶片时不落刀、不产生剪痕。
5. 剩余叶片保持完整，同层叶片沿平滑修剪轮廓收拢。辅助底图和明暗图案根据存活叶片重新生成：只填充互相覆盖的叶片之间，所有底图边界由完整叶片遮盖。稀疏、剪空和小叶再生时也不露出底图轮廓；不补生无法剪掉的装饰叶，叶片数量随真实修剪和生长变化。
6. 松手自动保存这一笔，剪刀归位、恢复整树显示。

可从外缘修形，也可在表面疏叶；持续修剪可以最终剪光整层乃至所有叶子。枝干由独立的剪枝玩法处理，修叶不会剪断枝干。

自由造型依靠用户落剪的位置和次数，不提供目标形状菜单。每片叶子的落剪只影响局部约 ±16° 的轮廓方向，重复修剪可逐步加深凹口，同时保留两侧凸起，供用户尝试爱心凹口、猫耳等细节。轮廓精度提升为 192 个采样点，平滑连接但不抹平局部细节。已有的低分辨率造型记录继续兼容。

叶片尺寸缩小为原来的 75%，成熟叶片数量约为原来的 1.6 倍，叶团生长半径扩大 12%，枝干与叶团连接位置不变。新造型以实际叶冠中央为中心，便于同时修出爱心的顶部凹口和底部尖端；旧记录保留原有的变形中心。

鼠标可直接在所选树冠上拖动。触摸时刀尖位于手指上方。键盘可用方向键选层及移动刀尖，Shift 加方向键以半个屏幕像素微调，空格选择或立即落刀。冠内空剪或键盘未命中时保留选层，可继续瞄准。Esc、手势中断及窗口失焦取消尚未松手的操作。

## 保存与恢复

新记录使用 leaf-3，保存被剪叶片的稳定标识，以及服务端根据落剪位置生成的整层形状数据，不保存擦除轨迹。一次拖动只提交一次；重试沿用操作 ID。保存失败时恢复已保存树形，并显示必要的错误信息。

旧 leaf-1 记录仍可重放。之前 leaf-2 原型保存的轨迹按完整叶片选择重放，历史记录保留，但不再渲染光滑擦除沟槽。

新剪掉的叶片休息 6–14 个生物小时后错开萌发，以平滑速度逐渐展开，48 个生物小时恢复叶量。新叶的位置和朝向各有小幅差异，随机结果绑定树种子、叶片和修剪时刻，刷新或保存调试时间线不会重新抽样。

树冠保留造型记忆：主要凹口、凸起和尖端长期保留，各方向以不同速度少量向外生长，慢速、连续的局部变化使轮廓保持自然。生长幅度有上限，不再在 240 小时后抹平造型，也不等比例放大整棵树。新长出的叶团继承同层形状；继续修剪时，在当前生长后的形状上累积局部修整，保存后不跳变。主页面、Gallery、分享图与时间回看共用修剪后的树形。作弊模式写入作弊草稿，沿用原来的保存流程。
