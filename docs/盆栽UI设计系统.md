## 1. 视觉方向

沿用当前模拟盆栽的简笔语言：自然收尖的枝干、成团的叶片、低饱和色块、安静的留白。盆器用简单轮廓、浅色盆沿与少量花纹表现差异。盆器提案使用平涂，不使用写实陶瓷纹理、光斑或复杂投影。原有树木的枝叶绘制完全复用，不在概念页中另画一套树。

树形 × 生长阶段 × 树的视觉方案，与盆形 × 盆色 × 花纹独立组合。切换盆器不改变树木骨架、种子、根部位置或镜头。宽高比例定义为盆口外宽 / 盆体高度，不含盆口厚度。

### 3.2 图层与连接

从后到前：盆体 → 盆壁花纹 → 盆沿 → 土面与苔色 → 树根和树木 → 根颈土面遮挡。

- 盆器局部原点始终对齐树木的根部原点。
- 盆沿使用相近浅色；土面 `#505141`、苔色 `#76815E`，与现有绘制保持连贯。
- 纹样裁切在盆体内部；所有实例使用独立裁切标识。
- 不拉伸或平移树木以迁就盆形；盆口宽度也不随生长阶段缩放。
- 高筒提供悬枝周围的纵向留白，其余盆形强调稳定的低重心。

### 3.3 五种花纹

素面：无装饰；竖纹：四根线；山岚：三个简化山峰与一个云形；横纹：两条轻弧线；几何：三枚半圆 / 方块。线宽基准 2 个逻辑单位。缩略图保留轮廓与大图形，避免增加细碎装饰。花纹颜色随盆色提供专用搭配，不由用户任选高对比荧光色。

| 类型 | 规范 |
|---|---|
| 背景 | 暖纸白 `#FAF9F3` |
| 正文 / 主操作 | `#35483B` / `#355D47` |

| 选中背景 / 焦点 | `#E8EEE2` / `#BD875C` |
| 字体 | 苹方、微软雅黑、系统无衬线 |
| 基础字阶 | 标题 28/40、章节 20/30、正文 14/22、辅助 12/18 |
| 间距 | 4、8、12、16、24、32；章节使用更大的组合间距 |
| 圆角 | 普通控件 12、展示卡片 16、主操作胶囊 999 |
| 状态 | 普通、选中、悬停、键盘焦点、禁用 |
| 移动端 | 操作热区至少 44px；横向内容改为换行和纵向堆叠 |
| 无障碍 | 颜色搭配文字或勾选；按钮带可读名称；标签页支持方向键、Home、End；遵循减少动态效果偏好 |

评审画廊编号等元数据可小于正文；日常操作文案遵循基础字阶。评审页宽屏标题为 36px，窄屏回归 28px。暖纸白是这轮固定画布；月夜方案在预览画布内部切换深色，控制区维持可读的浅色界面。

## 5. 审核页与产品边界

- 搭配实验室：独立切换树形、盆形、花纹、盆色、六套树色，以及初始化幼苗 / 成树；固定种子比较差异。
- 树形谱系：直接显示当前算法的七种成树，并提供跳转搭配。
- 盆器家族：八个起始组合、五种同形同色花纹对照、四层分解图。
- 色彩与天气：与搭配实验室共享树形、树色、生长阶段及设计盆器；七种天气和 15 分钟刻度的时刻滑杆驱动真实应用配色算法。提供四个时刻、六套树色的对照，以及实时材质色值和对比度。切换章节保留试色选择。
- 基础与组件：审核页固定基色、盆器原始色、字阶、间距和可点击的状态样本；动态色值及六套树色统一在「色彩与天气」比较。认领按钮只是状态演示，不创建数据。

场景试色可以切换「当前设计盆器」与「应用默认盆器」。前者保留选定轮廓、花纹和色系，并按背景修正明暗，属于新盆器审核提案；后者使用应用现有盆器和材质算法。默认盆器对照不会覆盖当前设计选择。两者复用同一树木样本；不请求定位、不写入盆栽数据。

新盆器颜色适配使用独立的 `--review-pot-body/rim/pattern`，保留应用现有树干、叶片与控件 tokens。盆体和盆沿相对地面基准色的对比度目标为 2:1，花纹相对盆体为 1.65:1；均为插画目标。土面与根部遮盖复用相同的动态苔色。

这套审核工具不代表未来首页要暴露所有选项。日常首页与观察页仍保持当前的安静布局。需要审核的核心是：八种轮廓是否保留、五种花纹是否够简洁、色彩是否与树协调、树与盆的比例是否合适。

## 6. 接入建议（本轮未实施）

审核后可用稳定的 `pot: {shape, tone, pattern}` 字段保存初始化盆器。需决定初始化随机分配还是提供有限选项；若继续随机分配，应由认领 UUID 的固定种子派生，与预览 / 服务端保存保持一致。旧记录缺少盆器字段时继续使用当前树形默认盆器，避免已有盆栽突然换盆。

审核页实现：`prototype/design-system.html`、`design-system.css`、`design-system.mjs`；独立盆器词汇表与绘制：`design-system-pots.mjs`；色彩章节：`colors.mjs`、作用域限定的 `colors.css`；新盆器色彩适配：`design-system-color-tokens.mjs`。没有修改正式盆栽配置和渲染入口。
