## 结论：以绘画色组为主，以生长与光照约束为辅

推荐目标是有体积的植物插画：远看是清晰饱满的冠团，近看有方向明确的叶片色块。保留真实的枝叶归属、冠龄、统一光向和遮挡关系；由经过审阅的色组与形状控制最终画面。不继续通过增强每个小叶簇的球形渐变来追求真实感。

## 新版可能失去美感的原因

| 当前实现 | 可能产生的视觉问题 | 调整方向 |
| --- | --- | --- |
| crownPaint 对每个 cluster 使用相同径向曲线 | 每团都长出一个类似高光中心，形成一串小球；缺少较大冠团的共同转面 | 在承叶小枝组层组织主光场，局部叶簇只做弱变化 |
| 同一原色乘连续能量，单叶噪声很小 | 原来明确的叶片色块融合成喷枪渐变，植物质感变弱 | 使用少量专门设计的亮、中、暗颜色；叶片按区域成组取色 |
| 叶龄、深度、受光连续叠加 | 单项都合理，最终颜色却未必协调；相邻团差异被抵消或夸大 | 多维输入决定有限色组的选择与分布，不无限改写色值 |
| 每个冠团完整展示同样的亮暗跨度 | 全树到处都抢眼，后部冠团也像前景独立球体 | 前部体积完整，后部收敛对比和细节，保留整体明暗秩序 |
| 遍历相交叶簇绘制柔影 | 同一视觉接触处可能叠加多次，暗部发脏；椭圆遮罩不跟随实际叶缘 | 以可见冠团接触为单位生成一个暗部掩模，限制累计强度 |

这些问题不说明多维模型无用，而是说明“数据维度正确”和“画面组织好看”需要分别设计。更换 OKLCH 或线性 RGB 不会自动解决色块面积、边缘与层次的问题。

## 研究依据与设计推论

- Pixar 的《Stylization at Pixar》展示了为画面目标调整阴影颜色、形状、边缘和明暗交界的做法。对本项目的启发是：光照提供方向与遮挡依据，最终阴影应受美术控制。[原文](https://renderman.pixar.com/stories/stylization-at-pixar)
- Barbara Meier 的《Painterly Rendering for Animation》讨论笔触大小、方向和纹理如何表现形体，以及动画中简化和稳定的重要性。对本项目的启发是：叶片不能只作为覆盖在光滑底色上的随机小点，应形成稳定、有方向的中尺度笔触组。[论文](https://media.disneyanimation.com/uploads/production/publication_asset/47/asset/p477-meier_1996.pdf)
- Bonsai Tonight 对木村真柏的案例描述包含较连续的树冠和分离枝团的不同组织。这里借鉴冠团与干势的关系，不从照片推导统一色值；同一棵树应有整体组织，而非每一小簇都获得相同视觉权重。[案例](https://bonsaitonight.com/2016/09/06/kimuras-shimpaku-bonsai/)

以下比例和算法均为本项目设计提案，不是上述资料给出的定律。

## 1. 用三个尺度组织颜色

**整树尺度：** 一套共同的绿色家族和一个光向，确定重点冠团与安静区域。前后差异首先来自遮挡，色组辅助识别；新叶鲜亮只占部分面积，不能所有顶部叶子一起变成浅色帽子。

**可见冠团尺度：** 同一承叶小枝或稳定的小枝组合共享一个主光场。让整个冠团有宽缓的受光面、圆润的侧面转折和紧凑的下部暗面。小枝归属不变，合并的只是着色组织，不合并剪枝对象，也不绘制大实心包络。

**叶片尺度：** 叶片在主光场指导下组成大小不同的色块与喷束。局部叶簇可以有弱转面，但不重复完整的亮面—暗部—反光套装。手机尺寸只保留能看清的笔触，避免细小噪点铺满全树。

## 2. 三个主色面，加两个少量点缀色

先从用户认可的旧版四级配色提取视觉基线，再手工审阅材质色组。不要再次从一个新选的绿色开始推导所有颜色。

| 角色 | 目标形态 | 起始面积预算 |
| --- | --- | --- |
| 主体中间色 | 保持叶冠的原色与统一感 | 约 55% |
| 受光色 | 大而不规则、相连的上部色块，略偏暖绿 | 约 25% |
| 背光色 | 下部与侧面的连贯暗面，保留绿调 | 约 17% |
| 鲜叶点缀 | 少量外梢喷束，亮而不发白 | 约 3% |
| 接触暗色 | 遮挡交界的局部短暗面 | 从背光预算中分配，默认不额外扩张 |

比例仅用于检查是否高光过多、暗面过碎，不按每个团强行填满。后部团可减少点缀色和内部跨度，前部主团允许更充分的转面。

亮、中、暗不只是同一 RGB 的缩放：亮部可稍暖、暗部可稍冷，但共享同一绿色家族。微调与插值可继续用 OKLab；光照不再无限放大或压低最终色值。首轮不默认绘制整圈反光，只有足够大的主团且底部确需分离时才试一小段弱反光。

## 3. 圆润依靠明暗面的形状，而非环状渐变

使用宽而偏心的受光区，侧面与底部的转暗区顺着冠团弧度包裹。明暗交界应有低频起伏和宽窄变化，表现叶面集合，不是椭圆等距环。

建议使用主光场与稳定低频区域场共同定义三个色面的归属：光场控制方向，区域场打散过于规整的边界。交界允许窄范围柔化；主体保留清楚色块，不做硬切卡通条带，也不做全域喷枪渐变。

叶片从当前位置的主色面及相邻一个色面中取色，同一小喷束共享偏好。受光面的少量暗叶表示缝隙，暗面的少量中间色表示叶片转向；禁止暗面随机出现最高亮色。边缘局部清晰、局部融入相邻团，避免每一团都被描一圈。

## 4. 多维系统改为有界的美术控制

| 输入 | 控制内容 | 不应做的事 |
| --- | --- | --- |
| 树种 | 色组家族、笔触形态与密度 | 只给所有树换同一绿色 |
| 叶龄 | young / mature 色组之间的小幅过渡，鲜叶点缀的比例 | 用高度直接把整团提亮到高光级别 |
| 深度 | 后中前的有限色组变体、细节与对比强度 | 为每团制造独立颜色，或强制前方永远最亮 |
| 整树光向 | 受光区朝向与各枝组的有限暴露差异 | 给所有叶簇相同位置的高光点 |
| 团内形状 | 三个主色面的分布与软硬边 | 不断加大黑白跨度来补偿形状问题 |
| 遮挡 | 接触处短而柔的暗面，取色于接收团的暗色组 | 叠加大量黑色透明椭圆 |

深度、年龄和光照仍独立保存，但最终共同选择有限色域内的绘画角色。需要对比时先调整可见交界处的色面，而不是将整个前团漂白或整个后团压黑。

## 5. 实现顺序与剪枝稳定性

建议新增独立 painterly 模式，保留当前版本和此前认可的配色，不直接覆盖。

1. 使用完全相同的枝架、冠形、种子与镜头，先恢复旧版色组和叶片色块可读性。
2. 按稳定支撑小枝 key 建立 paintGroup；使用未剪骨架确定光场坐标。剪除叶簇不重算幸存团的中心或半径，避免剩余叶片突然换色。
3. 只加入冠团级三色面，局部叶簇的转面降到从属地位。无叶片细节时，仍应读得出圆润体积。
4. 加回有方向的叶片喷束，保持三色面的面积与秩序。再生团独立建组，沿用整树色组。
5. 最后才接入叶龄、深度小幅变化和接触暗部；每步都与上一步比较，不能一次开启所有维度后凭感觉补参数。

树种差异通过笔触与色面组织表达：真柏采用细密不等大的喷束；榉树用较大的阔叶片及连贯拱面；文人松用疏朗针叶束和克制亮色。第一轮仍只验证真柏，避免在未认可的风格上扩展三树种。

## 6. 下一轮只做两个新候选

- A：叶片色块为主，三色面较清楚，渐变很弱。
- B：与 A 使用完全相同的色组、面积和光向，仅将转面边缘柔化，增加一点圆润感。

以此前认可版作为共同基线，当前多维版作为问题参照。先用同一真柏样本审阅，选出方向后再看另外四个种子、手机尺寸、灰度及剪枝。灰度用于检查层次和彩色丢失后的体积，不要求每个重叠都靠明度独立区分。

审阅的核心问题：远看像一棵组织清楚的树吗？单团圆润但仍像叶子组成的吗？叶片能被感知而不碎吗？新老和前后差异是否服务于整体？若只在放大截图上成立，手机上变成小球或杂斑，应退回上一步。
