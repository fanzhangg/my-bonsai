# 七种盆栽的结构与造型审核

入口：设计系统「02 树形谱系」与「10 枝序实验室」。本轮为可审阅的形态算法提案，正式认养的 `bonsai-growth-2` 回放和存储格式保持兼容。

## 继承现有算法

当前链路是 `core/v1/specimens.mjs → core/v1/canopy.mjs → morphology.mjs → growth.mjs → growing-render.mjs`。

- specimens 提供训练过的主轴、出枝位置，以及枝轴、冠区引导、混合策略的历史实验。
- canopy 在冠区中分布末端目标，递归拆分目标组，生成相连的细枝。榉树已有三组主分叉。
- morphology 处理连续收分、树种外形、枝龄、冠区遮挡和长期光照方向。
- growth 根据稳定节点 ID 回放生长与修剪；renderer 处理粗细枝、不同叶型、盆器、根盘与风动锚点。

问题：原先 `primary` 同时承担主要枝片与可修剪单元，细枝的生物层级和交互层级没有分开。大叶团又遮住了分枝，使各树形容易只剩“干线 + 几团叶”。上一轮独立的三级实验没有继承七种训练骨架。

本轮新增 `architecture.mjs`，直接调用现有 morphology，而非重画七个不相干的图标。继承训练骨架、稳定种子、生态冠区、曲线函数、叶片与盆器渲染。将冠区分给沿大枝错落附着的几根小枝，之后沿用二分目标组生成更细分叉。榉树的三组 bough 对应大枝，已有上升 primary 对应小枝。将较小的叶簇挂到细枝末端，保留枝间透光。

## 真实形态与艺术强调

树种与造型是两套概念：松可直干、斜干或风吹；真柏可曲干或悬崖。此处是典型组合，不表示植物只能长成这些形态。

| 样本 | 真实造型依据 | 本轮强调 |
| --- | --- | --- |
| 分层真柏 | 弯曲干线、横展枝片与间隙 | 加强曲干横向摆幅，鳞叶组成不等大云片 |
| 圆顶榉树 | 短直干向外上方多次分叉，冬态仍有圆冠 | 保留三组主分叉，展开小枝和细枝、缩小叶簇 |
| 文人松 | 清瘦干线，枝叶集中上部，大段裸干 | 仅保留高处三个枝片，拉长干线并减少冠体量 |
| 直干黑松 | 直立收尖主轴、底部宽展、顶部收拢 | 加强根盘与干基分量，保留不等距枝层和针叶束 |
| 斜干松 | 根上部整体倾斜，但仍可有反向平衡枝 | 增大倾角，保留两侧出枝，与风吹式区分 |
| 悬崖真柏 | 先上升再下折，末梢低于盆底 | 延长垂势，沿下行干线出枝，深盆承接 |
| 风吹松 | 干、枝共同表达长期单向风势 | 压低树高、拉长下风侧，小枝细梢统一向右 |

依据：[密歇根大学植物园造型说明](https://mbgna.umich.edu/styles-bonsai)、[Bonsai Empire 造型图解](https://www.bonsaiempire.com/origin/bonsai-styles)、[榉树结构与冬态](https://www.bonsaiempire.com/tree-species/zelkova)。造型参数为美术控制，不是测得的物种生长常数。

## 其他算法的取舍

| 研究 | 能解决什么 | 本项目采用方式 |
| --- | --- | --- |
| [Runions 等，2007，Space Colonization](https://algorithmicbotany.org/papers/colonization.egwnp2007.html) | 用空间中的目标约束枝条分布与树冠形态 | 保留本项目已有的冠区目标思路，按小枝划分目标组；本轮未实现论文的迭代吸引点竞争算法 |
| [Pałubicki 等，2009，Self-organizing tree models](https://algorithmicbotany.org/papers/selforg.sig2009.html) | 芽和枝条竞争光/空间，结合内部调节，支持修剪和弯曲 | 继承已有光照/枝龄影响，后续再将资源竞争接入真实生长事件；不把即时萌芽按钮当作生理模拟 |
| [Wu 等，3DBonsai，2025](https://arxiv.org/abs/2504.01619) | 用空间殖民生成结构先验，再结合 Gaussian Splatting 生成三维盆景 | 借鉴先确定骨架再生成外观的顺序；目前保留可剪、可追踪的 SVG 枝条图，未引入训练或三维生成管线 |

工程判断：继承美术训练骨架、冠区约束与递归细枝的混合方案，最适合当前轻量二维交互。纯随机分叉不易保证七种剪影；只有叶团外观也不足以支持可解释的局部修剪。

## 两级交互与完整枝序

`order = 0` 为主干，1 为大枝，2 为小枝，3 及以上自动生成并跟随所属枝条。手机和桌面都只显示「剪大枝／修小枝」。修小枝时先选所在大枝，仅显示该大枝下的少量选择点；下拉列表提供不依赖小目标点击的操作方式。

整枝疏除删除整个后代子树。回剪保留 62% 曲线，按附着参数删除远端后代，并将近端子枝的附着参数重映射。剩余枝条与相机不动，叶簇随所属节点消失。62% 是便于审核的固定位置，不是实际园艺剪口建议。

## 验收与真实性边界

在同一样本中比较现有算法和新提案，依次看完整枝叶、骨架、单色剪影；切换克制/鲜明/夸张与五组样本。每张卡片可载入相同种子、造型参数和盆器试剪。通过多个种子、不同强调值验证连接、收分、画面边界、典型造型指标、两级修剪与叶簇归属；这些检查不能替代用户对美感和自然度的审核。

本轮保证的是连贯的结构、可辨识的造型和一致的剪除反馈。仍是二维投影与训练骨架驱动的形态模拟，尚无三维枝条避碰、真实芽位/节间、蟠扎力学、季节休眠、伤口愈合或能量守恒。萌芽为确定性演示，松柏类裸枝不自动回芽；不能据此预测真实盆栽何时恢复。正式采用前应先验收外形，再设计新版本生长/剪口事件及历史兼容方案。
