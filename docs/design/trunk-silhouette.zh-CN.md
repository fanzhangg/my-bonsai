# 主干剪影：盆景造型原型

主干是人为选择与修整后的视觉骨架。目标是压缩自然树的尺度、表现年龄和姿态，不以还原自然生长轨迹为目标。

## 设计原则

1. **根基稳，上部轻。** 根颈有承重感，树身从土中连续长出，避免细棍插在盆中。根部宽度必须与盆口协调，不靠无限放大根盘补救比例。
2. **收尖鲜明而连续。** 下部粗壮、中部明显变细、上部仍有支撑冠顶的力量。粗细变化跟随段落和转折，避免等粗软管、倒收尖及突然断阶。
3. **先有大走势，再有细弯。** 以少量强转折建立重心与辨识度；弯的幅度、长短和曲率不等，避免规则等距 S 形。转折处有力度，但不能变成断裂折线。
4. **高度服从树形。** 真柏可矮壮、曲折；榉树强调稳定根基与向上分展；文人松保留清瘦长干与大留白。不存在所有盆景通用的矮粗比例。
5. **枝冠围绕干势组织。** 主干变化后须重新连接侧枝，留出关键转折和分叉。树冠沿用已认可的固定层次色组，不用换色掩盖枝架问题。
6. **剪后仍有姿态。** 裸枝剪影应独立成立。剪除侧枝不移动或重新生成幸存主干，撤销精确恢复；更换种子也应保持根基与收尖约束。

依据：[Bonsai Empire：主干的形状、收尖与粗度](https://www.bonsaiempire.com/basics/styling/trunk)、[盆景主干塑造：根基与收尖](https://www.bonsaiempire.com/blog/bonsai-trunk-creation)。以上是针对本项目的设计归纳，参数为视觉实验值，不是园艺定律。

## 当前原型

Design System 新增「真柏 · 主干剪影」，左为现有枝架，右为候选，两侧固定层次色组。首轮主干高度为原来的 80%，横向走势放大至 155%，加粗系数从顶部约 1.12 向根部约 1.60 过渡；侧枝垂直跨度收至 90%，叶冠保持原尺寸并随支撑枝端移动。

此轮沿用原有不规则主干路线并强化比例，尚未重画不同走势家族，也未增加表皮、枯干或新根系。只在真柏原型启用；认养、存档与其他树形未切换。先审核裸枝的比例和走势，再审核完整枝叶是否拥挤、盆口与根基是否协调。

## 侧枝风格化第二轮

顶部新枝长度回收：配合较少的分叉层级，将此前顶部额外延长上限从 52% 收至 15%，最顶部相较上一版缩短约 24%。下方老枝长度保持，顶部仍保留少量冠下可见长度；以下 52% 记录为历史调整。

顶部新枝的层级：保持上一版枝长、粗细和弧线，用主侧枝附着的主干段形成次序估算相对枝龄。最年轻约 30% 的枝族暂不生成第三级小侧枝，叶簇仍留在二级支撑枝端；较老枝族保留第三级。此为审阅用的枝龄近似，不是重新启用已否决的整套侧枝生长模型。

主干生长预览：Design System 不再固定调用成熟度 1，默认展示 25% 幼树，并提供 0–100% 生长进度。“生长 24 小时”按该树成熟周期推进进度，成熟后仍可观察剪后再生。复用现有由下向上逐段伸长、随成熟度增粗的流程；成熟造型算法不变。拖动进度会重置本页剪枝，避免倒退生长时保留未来剪枝记录。

侧枝生长模型实验已被用户否决并撤回。当前恢复 trunk-review-8，沿用以下侧枝比例、分叉与顶部加长方案。

顶部可见线条：考虑树冠会遮住部分枝端，树高上部约三分之一的侧枝逐渐加长，最顶部增幅上限由 32% 再提高到 52%（相对未加长版本）。横向和纵向跨度同比放大，保留原有出枝方向与末端抬升；三级小枝随父枝长度调整，仍受原长度上限约束。叶簇随支撑枝端移动，保持冠体大小，让枝线有更长的可见伸展段。验收同时看裸枝和完整枝叶，不以裸枝长度单独判断。

枝干模拟的核心是体现线条的美感：优先组织主线的走势、弧度、转折节奏，以及分枝的呼应与留白。衔接处理应服务于整条枝线，不能为了局部圆滑而填厚叉口、削弱线条张力。分叉圆弧补片方案经视觉审阅后撤回，恢复上一版（trunk-review-6），后续调整以整体线条美感为验收标准。

层级递减放缓：二级枝适度延长并加粗，一级枝段末端保留起点粗度的 72%，二级保留 62%。三级长度从父枝跨度的 36%／48% 提升为 52%／64%（保留 13–36 的画布长度边界）；三级根部粗度为连接处父枝的 82%，末端保留自身根部的 64%。弧线角度、分叉数量、层级和剪枝归属不变。参数为当前真柏审阅值。

增加疏朗的第三级：在每条承叶枝上只增加一条从属小侧枝，共增加 12 段，细枝总数为 24。内外枝的分叉位置和长度错开，新增枝起始方向沿父枝局部切线，再逐渐展开；粗度小于连接处父枝。约三分之一原叶簇随新枝端移动，其余保留在父枝，保持原叶量和固定色组。禁止继续递归生成第四级细碎分叉。已更新多样本连接、剪枝和撤销验证。

最新修正（连续弧线）：撤销将末级枝简化为固定角度直杆的做法。采用顺势出枝、中段舒展、末梢渐抬的弧线；承叶枝起始切线与父枝局部切线的偏差限制在约 11.5° 内，之后逐渐转向。内枝短抬、外枝长展，仰角按稳定枝条标识作小幅变化，避免重复平行叉。保留 12 段承叶枝、既有剪枝 ID 和固定层次色组。

研究依据：Bonsai Empire 的[真柏蟠扎案例](https://www.bonsaiempire.com/basics/styling/developmental-exhibitive-wiring)区分自然向上生长、培养时向外展开和展览时组织枝团的不同目标，说明盆景侧枝并非越细越直立。Bonsai Tonight 的[真柏曲线练习](https://bonsaitonight.com/2021/04/09/bonsai-development-series-23-wiring-young-juniper-trunks/)指出等长、重复半圆弯会显得机械；此处借鉴不等幅、不等长的曲线节奏，而非把主干练习直接当成侧枝规则。切线和角度范围均为本项目的二维造型约束，不是园艺或力学定律。

末级枝姿态修正：主侧枝保留承重横展曲线，轻的末级承叶枝改为更直、更向上的走势，内枝与外枝分别采用约 60°、46° 的仰角，并取消末端下垂钩形。保持枝段长度、层级数量和剪枝归属，叶冠跟随支撑枝端移动。这是基于承重与向上生长直觉的造型约束，尚未计算枝叶载荷、截面刚度、弯矩或向光性，不称为物理模拟；不能把“层级越后必然越直”当成普遍生物规律。

移除末端三级小分叉，每条主侧枝保留两条有长短区别的承叶枝，细枝总数由 28 降至 12。一级侧枝略延伸，内侧短枝与外侧长枝分别强化抬升和横展，末端用上扬弧线收束；根部沿父枝走势出发，避免生硬直角。承叶枝适度加粗并保留收尖，不再逐层缩成细碎针线。

原三级枝的叶簇归并到其保留的父枝端，保持叶簇自身尺寸、接枝偏移和固定层次配色。六个主要可剪枝 ID 保持；剪枝删除对应枝族，幸存枝架不移动。已检查裸枝与完整枝叶效果。
