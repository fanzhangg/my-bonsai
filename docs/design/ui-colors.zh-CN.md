首页和领养页使用相同的天气场景与材质颜色。颜色只参与渲染，不改变树的种子、形状、生长时间或认领时的位置。

## 背景

采用低饱和、低局部反差的三段渐变。白天为浅青灰至暖纸色；晨间淡紫灰至米色；傍晚灰紫至浅杏色；夜间深蓝灰至墨青色。雨天和阴天混入冷灰，雪天混入浅银灰。雾层位于树后，夜间降低不透明度，避免冲淡树的轮廓。

## 盆栽材质

`prototype/color-system.mjs` 从天气场景和既有外观方案生成 CSS tokens：

- `--bonsai-bark`：树干、分叉、根部统一用色，维持连接处连续。
- `--bonsai-leaf-0..3`：叶团阴影、主体、受光、高光，保留绿、红、金、蓝等原始色系。
- `--bonsai-pot-top/bottom`、`--bonsai-rim`：陶盆渐变和盆沿。
- `--bonsai-soil/moss`：土壤与苔面，根部遮盖与苔面使用同色。

取消整树 brightness/saturate 滤镜及夜间投影。暗背景下叶色混入柔和灰绿色月光；树干、叶片和盆体分别按局部背景明度修正。树干目标对比度 3:1，叶色最低 1.65:1，盆沿和盆体 2:1。这些是插画的视觉目标，不是整页无障碍合规声明；渐变不同位置、透明叶团和细小枝条仍需视觉检查。

## 控件

`--ink/muted/surface/border/action/action-ink/focus` 分别负责图标、辅助信息、调试面板、边界、主要操作、按钮文字和键盘焦点。主按钮为白天深苔绿、夜间浅灰绿。图标不再用整体透明度削弱可读性。按钮文字和顶部图标的基准对比度目标为 4.5:1。

调试模式原有的外观、天气和时间控件可直接组合预览，不增加正常页面 UI。独立算法渲染继续使用原始外观；应用的透明 SVG 才使用动态 tokens。

## 验证

颜色测试覆盖六种外观、七种天气、每 15 分钟一个时间点，验证 token 有效性和基准对比度；原有几何、生长及天气测试继续运行。真实定位不可用时仍采用设备时间的配色。
