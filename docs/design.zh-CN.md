# 我的盆栽 · 游戏设计

[English](design.en.md) · **简体中文** · [README](../README.md)

本文介绍当前游戏的核心体验。中英文版本范围一致，修改时应同步更新。[原 MVP 提案](一盆树-MVP设计文档.md) 保留为历史背景；其中的参与者系统、每日剪枝限制及确认流程不代表当前游戏。专题研究与实现记录保留原有语言。

## 1. 游戏体验

我的盆栽是一款安静、手机优先的网页游戏。玩家认养一棵有特点的幼树，观察它生长，并通过小幅互动塑造它。固定链接让玩家随时回来，也能邀请另一个人在不同时间照料同一棵树。

游戏没有分数、胜负条件或定时任务。主角是树本身：它的轮廓、枝间的留白，以及随着时间逐渐显现的变化。

## 2. 核心循环

**遇见 → 认养 → 观察 → 修剪或浇水 → 离开 → 回访。**

| 时刻 | 玩家动作 | 结果 |
| --- | --- | --- |
| 遇见 | 打开首页，观察随机生成的幼树。 | 一棵具有独特外观和盆器的树等待认养。 |
| 认养 | 可选填名字，认领眼前的树。 | 预览中的树被保存，获得 `/t/:id` 固定地址。 |
| 回访 | 打开固定链接。 | 简短回放呈现生长过程，然后展示当前状态。 |
| 造型 | 拖动剪刀靠近旁支，松手剪下。 | 目标枝条被移除，主干保留；后续生长根据剩余树形展开。 |
| 照料 | 将水壶移到花盆附近。 | 浇水提供即时视觉反馈，并影响树的生物时间。 |
| 分享 | 使用分享按钮，或发送固定链接。 | 另一个人可以探望并操作同一棵树。 |
| 探索 | 从首页进入小院。 | 浏览活跃盆栽，选择一棵前去探望。 |

只看一眼也是完整的一次体验。新枝需要时间生长，剪枝不会立即补回被剪掉的枝条。

## 3. 树与生长

- 新树采用带版本的 `bonsai-growth-3` 模型，拥有七种树形、相容的冠型和叶形、配色与随机盆器。稀有配色及适用树形的特殊叶形增加个体差异。
- 认养预览和保存后的树使用同一份生成设计。刷新已保存的树不会重新抽取外观。
- 生长由时间、已保存设计及操作历史重建，无需持续运行后台模拟。
- 剪枝改变存活结构。逐渐长出的新枝保持树形风格，为玩家的造型选择留下空间；自然枝量上限防止无限生长。
- 新树默认版本调整后，旧树仍保留已保存的模型版本和历史。

生长节奏属于加速的视觉模型，不声称模拟真实植物。具体规则见 [v3 生长与剪枝参考](v3剪枝与生长集成.md)。

## 4. 交互与视觉

树占据主要画面。剪刀与水壶是可以拿起、移动的场景工具。以触屏操作为主，主要工具同时提供键盘操作与无障碍标签。反馈应清楚表达目标与结果，不让常驻说明挤占画面。

平涂色块、清晰轮廓、克制的控件与叶层间留白，让小屏幕上的树仍然易读。时段背景与天气营造氛围。实时天气需要启用配置并获得定位权限；没有定位时仍可使用设备时间。

修叶目前是 `/leaf-trim.html` 上的独立实验，结果保存在当前浏览器。它探索逐片去叶与树冠轮廓记忆，不应被描述为已接入主游戏、由服务器保存的工具。见 [修叶设计](修叶与树冠微整形设计.md)。

## 5. 分享与小院

每棵树拥有固定地址。当前没有账号或所有者权限：持有链接的人可以探望和操作。给树起名不等于用户身份认证。

支持时使用系统分享面板，否则复制邀请文案和链接。已准备好的 PNG 可随分享附上；服务器生成的预览图让分享平台无需执行 JavaScript 就能展示已保存的树。

小院以图片展示最近活跃的已认养盆栽，按批加载并仅绘制附近项目，保持浏览流畅。访问与成功互动决定活跃度；加载小院缩略图不计为逐棵探望。

## 6. 语言

首页、盆栽详情和小院支持英文与简体中文。首次访问使用浏览器偏好列表中第一个受支持的语言，无匹配时使用英文。中文地区变体统一显示简体中文。

首页语言菜单提供英文、中文和跟随浏览器三项，手动选择沿用于主要页面。树名与搜索输入保持原样。客户端分享邀请跟随界面语言，服务器生成的分享元数据保留中文默认。开发样本页不属于当前应用界面的国际化范围。

本中文设计文档与 [英文版](design.en.md) 构成对应的产品设计入口。核心循环、功能状态或语言行为变化时，应同步更新两份文档。

## 7. 实现边界

| 部分 | 当前方案 |
| --- | --- |
| 客户端 | `prototype/` 中的浏览器模块与 SVG 渲染。 |
| 服务端 | `server.mjs` 提供应用页面与 API。 |
| 存储 | 生产环境使用 PostgreSQL，本地可使用单进程 JSON 存储。 |
| 托管配置 | Render 提供应用服务，Neon 通过 `DATABASE_URL` 提供 PostgreSQL。 |
| 模型兼容 | `prototype/core/` 下按版本保留引擎，维持旧树行为。 |
| 验证 | 仓库测试与适当的浏览器检查；本地 JSON 测试不代表真实 Neon 或部署验证。 |

本地启动、CI 与部署配置见 [README](../README.md)。[实现参考](implementation-notes.zh-CN.md) 保留详细功能记录和研究入口，其中包含可能已被后续方案替代的历史描述。
