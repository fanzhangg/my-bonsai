# 从种子到盆景：渐进生长 v2

2026-09-16，应用当前采用 `bonsai-growth-2`。替代观察版最初仅展开树冠、主干始终成形的实现。

- 每个种子确定一个 3–6 天的成熟时长；刷新、重启不会改变。该时长从认领时开始计算。
- 认领时已有弯曲主干和至少两根展开的主枝，可没有叶子。按树形设初始进度：真柏/黑松/斜干/风吹 30%，悬崖 35%，榉树 50%，文人松 55%。已移除额外叠加的幼枝和三片幼叶，全部枝叶来自实际树形。
- 回放从 0% 的种子开始，到此刻真实生长状态结束，约 4 秒。新认领的树只回放到幼苗，不提前展示成熟树。无进度条。减少动态效果偏好仍直接显示当前状态。
- 主干、主枝、细枝按父子顺序出现，每段都有独立的出生时刻和展开时长。子枝起点沿变形后的父枝曲线移动，保持相连。
- 每段曲线相对连接点伸长，同时全树体积逐步扩大、木质部分逐渐增粗；成熟时恢复原有七种造型。
- 叶团只在支持枝长出后形成，团内叶片按稳定序号逐渐增加；叶团核心的透明度也随叶量增加，而不是直接出现完整冠层。
- 成熟时间之后固定保持成熟状态，不无限扩张。不模拟真实光照竞争或植物生理。

实现：`prototype/growth.mjs` 计算阶段和变形；`growing-render.mjs` 绘制递增的叶量；`playback.mjs` 把种子至当前阶段映射到 4 秒。原 `life.mjs` 留作旧模型的历史代码与测试，不再用于观察版页面。

调试模式保留时间滑杆、快进、重播、树形、外观和种子。面板显示随机成熟天数与生长百分比。所有调试修改仍仅作用于本机预览。

旧链接继续使用原种子、配置和创建时间，以新的渐进生长方式显示。旧修剪记录留在存储中，观察版 v2 不重放修剪。

测试覆盖七种树形 × 三个种子，验证初始主干已有造型、至少两根主枝、没有额外小芽、木质增粗伸长、枝序与叶量单调增加、3–6 天成熟、成熟后稳定、种子首帧及回放终帧一致性。


## 固定花盆构图

应用使用统一 740 × 740 的画幅，水平中心固定在花盆中心，土面距画幅顶部 470。七种树形、随机种子及所有生长阶段采用同一缩放和锚点，不再用最终树冠的包围框决定镜头。画幅为风吹、斜干和悬崖留出空间；SVG 居中等比缩放。
