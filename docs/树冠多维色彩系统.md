# 树冠多维色彩系统 · 设计提案

后续审阅反馈：此版本的美观与形象感未达到此前认可版本。新的研究方向见[树冠色彩风格再设计](树冠色彩风格再设计.md)，优先调整冠团级色面与叶片笔触组织，暂不继续增强逐叶簇径向明暗。

2026-09-17。设计提案及首轮原型，待审阅。适用于当前 Design System 候选树冠；不改变枝架、叶簇轮廓及剪枝归属。承接《树冠算法改进方案》的长期设计准则。

## 首轮原型状态

已接入真柏「多维色彩」对照：两侧使用相同枝架与叶冠，左侧保留上一版固定层次色组，右侧使用独立材质与光照。提供左上、右上、中性漫射光，以及深度辅助、叶龄和冠内体积开关。桌面及 390px 手机预览已检查，全量测试通过。

当前实现使用 OKLCH 参数生成线性 RGB 原色，再乘以环境与主光强度；采用统一的柔和径向光场近似冠面，基底渐变采样该光场、叶片在自身位置求值。尚未使用完整椭球法线或局部遮挡。初始叶龄仍沿用枝组近似；再生叶龄按自身展叶后的时间独立成熟，96 小时为原型参数。当前只实现绿色真柏，未实现三树种材质切换、灰度模式、九宫格、季节变化或动态投影。以下章节保留完整目标设计，不能视为全部已实现。

## 目标

同一树种保持共同的原色，但不同冠团因叶龄、空间位置和受光产生相互协调的色调；每个冠团内部又有亮面、过渡面、暗面，表现饱满体积。整树统一光源，局部差异有原因，不能用独立随机颜色代替空间与生长关系。

原色是中性光下的叶片材质色，不是画面上每个位置最终显示的颜色。使用便于美术调整的 2.5D 近似，不声称是完整植物生理或物理光照模拟。

## 一、七个独立维度

冠团体积修正：把原先较均匀的径向衰减改为绘画式明暗曲线，依次组织宽缓亮面、半调、明确转暗、核心暗部和克制的边缘反光。亮面稍暖，暗面保留绿色，降低单叶噪声对大体积的干扰；渐变和单叶继续共用同一曲线。冠形、枝冠连接和前后层次参数不变。此轮代码及测试已完成，浏览器视觉复核因工具用量限制尚未完成，圆润程度仍待审阅。

原型层次修正：深度明度偏移由 ±0.025 调到 ±0.045，并小幅调整彩度与色相，让前后冠团更容易分辨。加入可关闭的「重叠柔影」：仅对不同支撑小枝、不同深度且投影相交的叶冠生成柔和接触暗部，裁切在后方叶冠内部，前方叶冠仍按原顺序覆盖。剪除遮挡叶冠后对应暗部消失。这是二维遮挡提示，不模拟真实太阳投影；以下原始参数预算以此轮审阅为准。

| 维度 | 输入及归属 | 主要影响 | 约束 |
| --- | --- | --- | --- |
| 树种原色 | 整树 species / season | 基础色相、彩度及明度范围 | 全树共享一套材质，不为前中后分别手写无关色组 |
| 叶龄 | 叶簇 birthTime / maturity | 新叶至成熟叶的材质过渡 | 独立于树高、枝龄；顶部仅能作为旧数据的回退近似 |
| 前后深度 | 枝组及小枝 depth | 遮挡顺序、轻微明度与对比修饰 | 近景盆栽不模拟明显大气雾；后深前浅是克制的美术辅助 |
| 整树受光 | 全树光向、冠团方位与暴露程度 | 整团受光强弱 | 左右位置只是近似，不能假定左边一定向光 |
| 团内体积 | 冠团表面方向与光向 | 亮面、半调、暗面 | 与整树使用同一光向；不能每团自带一盏灯 |
| 局部遮蔽 | 冠团实际重叠和接触 | 重叠处的柔和暗部 | 屏幕上重叠不等于一定挡住光，不给所有冠团描黑边 |
| 叶片微差 | 稳定叶片 key | 小幅明度、彩度扰动 | 幅度最小；不改变大面积明暗关系 |

天气属于光照预设，季节属于材质预设。二者不可通过整体透明度或同一层颜色滤镜混在一起。

## 二、材质色：先决定叶子本来的颜色

在 OKLCH 中配置材质，L 为明度、C 为彩度、h 为色相角。首轮仅以当前已认可的绿色为参考起点，以下数值是待视觉校准的建议值，并非实测叶色：

| 材质预设 | 成熟叶基色 L / C / h | 新叶变化方向 | 表现定位 |
| --- | --- | --- | --- |
| 真柏 | 0.51 / 0.075 / 145° | 略亮、略偏黄绿 | 沉稳绿底，保留细密叶感 |
| 榉树 | 0.56 / 0.095 / 137° | 更亮、黄绿倾向稍明显 | 较清新的阔叶冠 |
| 文人松 | 0.47 / 0.065 / 150° | 适度提亮，色相变化较小 | 克制的深绿针叶冠 |

每种树保存 young 和 mature 两个材质端点，在 OKLab 中平滑插值。绿色预设的新叶相对成熟叶可先试 ΔL = +0.04～+0.07、ΔC = 0～+0.015、色相向黄绿小幅移动。正常成熟后停止变暗；衰老、黄叶与季节变化应有独立状态，不能用“越老越黑”无限外推。

叶龄由出生时间和显式生长时钟计算，成熟时长是可调的产品参数。旧数据缺少出生时间时，沿用当前枝组年龄近似并标注 ageSource；新生叶必须记自己的出生时间，不能继承老枝的深色。

颜色空间转换与插值参考 [W3C CSS Color 4](https://www.w3.org/TR/css-color-4/)。OKLCH 用于材质与美术调参，光能合成使用线性 RGB，输出才转回 sRGB；不直接把 hex 通道相加或混白来表示所有光照。

## 三、光照：整团受光与团内体积共同求值

使用一个共享的柔和主光和环境光。首轮固定左上前方的中性偏暖主光，环境光轻微偏冷；提供中性漫射光用于检查原色。默认不加入强高光、透光、轮廓光或天气投影，防止叶团像塑料球。

坐标约定：x 向右、y 向上、z 向观察者。SVG 的向下 y 在计算前翻转。光向为指向光源的单位向量。

每个冠团用低矮椭球体近似体积，实际轮廓继续使用已有自然叶簇路径。局部位置按宽、高、厚度求近似表面法线 N；深度厚度仅用于着色，不重新生成枝架。叶簇边缘的非椭圆扰动映射到有界局部坐标，避免边缘计算出现无效值。

```text
albedo = leafMaterial(species, season, maturity)
groupExposure = exposureOfGroup(groupOrientation, treeEnvelope, light)
diffuse(p) = max(0, dot(normal(p), lightDirection))
direct(p) = groupExposure × diffuse(p)
illumination(p) = ambientRGB × ambientStrength × ambientVisibility(p)
                + sunRGB × directStrength × direct(p) × sunVisibility(p)
lit(p) = linearRGB(albedo) × illumination(p)
result(p) = boundedDepthAndDetailAdjustment(lit(p), depth, stableLeafKey)
```

上述乘法对 RGB 分量分别计算。groupExposure 表示枝组的整体暴露，不是第二遍叠加相同的 dot(N,L)；法线决定团内明暗。首轮暴露可由冠团相对整树中心的方位作弱近似，保留非零下限；未来有空间遮挡数据后再替换。太阳被挡与环境遮蔽分开，防止重复把同一重叠区域压黑。

柔和光初始可试 ambientStrength = 0.65、directStrength = 0.45、groupExposure = 0.65～1.0。这些是相对权重，须统一曝光并进行输出色域处理，不能将超过范围的通道逐个硬截断。阴天提高环境光占比、降低主光占比；不更改叶龄或材质端点。

## 四、一个冠团的颜色不是单一 shade

每团从同一材质和光场派生五个绘制角色，角色不是五条可见色带：

| 角色 | 位置与用途 | 相对中间调的初始 ΔL 预算 |
| --- | --- | --- |
| 受光面 | 朝主光的宽缓冠面 | +0.07～+0.11 |
| 亮半调 | 受光面向主体过渡 | +0.03～+0.05 |
| 中间调 | 展示原色与叶龄差异 | 0 |
| 背光面 | 远离主光、下部转折 | −0.06～−0.10 |
| 接触暗部 | 有遮蔽依据的局部重叠 | 最多再降低 0.02～0.04，面积须小 |

这些区间用于校准光场输出的感知幅度，不是在物理合成后再次完整叠加一遍。阴影保留绿色与环境色，亮部保留彩度，避免纯黑阴影和白色高光。

SVG 基底使用覆盖真实冠形的宽缓渐变，单叶在其实际位置采样同一个光场。仅用同一套 palette 仍不够：叶片若随机选择亮暗色，会与底层光向矛盾。首轮可将连续光场量化为 5～7 个缓存颜色桶，再加小幅稳定差异；渐变和单叶必须通过共享 shadeAt() 求值。

## 五、分离空间深度与明暗强度

深度首先决定遮挡，而非颜色。初始审美预算建议：前后层 ΔL 不超过 ±0.025，后层彩度及团内对比最多降低约 5%～8%；单叶随机 ΔL 不超过 ±0.008。均需手机审阅后校准。

优先级为：冠团体积明暗 > 新老叶差异和整树受光变化 > 深度辅助色差 > 单叶微差。不要同时把所有参数推到上限。色差叠加后用整树统一的曝光和色域压缩保持绿调，避免一团发白、一团发黑。

例如后方新冠的向光面应允许比前方成熟冠的背光面更亮；“前方永远最亮”会破坏光照和叶龄逻辑。前后仍靠遮挡、边界和局部对比辨认。相邻同龄同光的两团允许颜色接近，无需强行为每团制造一种颜色。

## 六、数据与现有代码的迁移

建议单独新增 crown-color.mjs，提供纯函数：

```text
resolveMaterial(species, season, maturity) -> albedo
resolveCrownLighting(crown, treeLighting) -> lightingContext
shadeAt(material, lightingContext, localPosition, leafKey) -> displayColor
buildCrownPaint(...) -> gradientStops + leafColorBuckets
```

树级保存 colorVersion、materialPreset、lightDirection、光色及强度；枝组保存稳定 depth、orientation；叶簇保存 birthTime、ageSource、supportNodeId、stableKey。几何模块不再生成最终 hex 配色。

当前 crown-baseline.mjs 的三套 layerPalette、crownTone 和 RGB tint 由上述系统替代；保留 crownLayer 及 woodDepth 负责空间排序。growing-render.mjs 的 radialGradient 与 surface 计算改用同一着色上下文，避免两个近似各自调参。depth 开关仅关闭深度色彩辅助，不应同时关掉年龄与体积着色。

同一小枝共用材质年龄来源与枝组暴露，局部叶簇可以有不同表面法线。缓存按材质、年龄档、光照上下文与深度档复用；不新增逐叶 SVG 滤镜或逐帧重算整树。

剪枝不改变幸存叶簇的年龄、深度、随机数及固定暴露参数。首轮不模拟剪后动态投影；后续若加入遮挡更新，只让受光变化平滑过渡。年龄渐变是生长时钟驱动的正常变化，需与剪枝引起的突然换色区分。版本化后才接入存档，旧树保留兼容回退。

## 七、Design System 审阅方案与实施边界

先仅在真柏固定枝架实现，左侧保留当前已认可版本，右侧为新系统。加入以下控制，默认仍只呈现一棵完整候选树：

- 材质原色 / 加叶龄 / 加深度辅助 / 加整树受光 / 完整体积，可逐项开关诊断。
- 左上光、右上光、中性漫射光三个预设，以及原色、灰度观察。
- 固定冠团做 3 个深度 × 3 个叶龄的九宫格，统一光向与几何；每格都有自身亮暗面。用于检查各维度，而非给应用用户展示参数。

验证要求：换光不改几何、原色和年龄；同叶龄换深度只产生克制差异；漫射光仍能看出原色与年龄；团内明暗与全树光向一致；后方受光新冠不被强制压到最暗。手机检查不发灰、不发荧光、不呈塑料球、不变回平涂色块。

自动验证覆盖色值有限且在输出色域内、固定参数确定性、材质和光向解耦、剪枝幸存对象稳定、撤销恢复和再生年龄独立。随后在真柏多个样本审阅；通过后再校准榉树、文人松的材质端点。首轮不实现季节演进、真实投影或完整光能传输。
