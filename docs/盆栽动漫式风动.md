# 盆栽动漫式风动

## 当前动作设计

风动集中在细枝与叶片。主干、底部和粗枝作为稳定骨架，不再使用整树倾斜或按高度变形。

- 主干（trunk）及根节点固定。
- 枝条宽度达到根部主干宽度的 24% 时，自身不摆动；阈值下限为 0.8 SVG 单位。
- 较细枝条按 `(1 - 枝宽 / 阈值)²` 获得柔度，越细越灵活。
- 子枝绕自身与父枝的连接点旋转，继承父枝的运动；圆角连接、枝条长度与轮廓保持完整。
- 主摆周期约 4.7 秒，逐级加入相位滞后和柔和回弹，避免所有枝梢同时换向。
- 叶团继承支撑枝的姿态，再围绕枝梢叠加小幅错拍摆动。
- 普通天气强度为 1，大风 1.2，雷雨 1.35，约 1.8 秒尺度平滑过渡。
- 花盆、土壤和根系固定。悬崖式树形沿用同一父子枝条机制。

这是一套风格化二维骨架动画，不是弹性力学求解。

## 实现与验证

`prototype/growing-render.mjs` 为木质组输出节点索引、父索引、角色、宽度与锚点，并为叶团标记支撑枝。
`prototype/wind.mjs` 按父子关系合成旋转矩阵，只更新组变换，不重建枝条轮廓或叶片细节。动画独立于生长进度；生长重绘后沿用运动时钟。隐藏页面暂停，系统减少动态效果时移除全部动画变换。

`tests/wind.test.mjs` 验证主干与粗枝固定、细枝柔度、连接点一致、温和幅度、重绘相位连续、后台暂停和减少动态效果。
