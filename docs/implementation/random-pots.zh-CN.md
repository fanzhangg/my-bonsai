# 随机认养盆器

新盆栽从设计系统的八款完整搭配中随机分配盆器。盆形、颜色与花纹作为 `config.pot = {shape, tone, pattern}` 一同保存，使用认领 UUID 独立派生，前端预览和服务端认养得到相同结果；重复提交、刷新链接与生长回放不会重新抽取。

八款为砂白浅椭圆、青瓷圆腹、赤陶折方、墨蓝高筒、青花山岚、雾粉花瓣、苔绿横纹、暖黄几何。本次保留这八款已审核组合，不随机拼接额外的颜色和花纹。切换树形或生成时间不会影响已保存的盆器。

`pots.mjs` 提供应用与设计系统共用的轮廓、色板、预设及 SVG 绘制。盆器固定对齐树根，不参与风动；树形、枝叶、镜头和生长计算保持原状。`color-system.mjs` 为盆体、盆沿、花纹输出 `--bonsai-vessel-body/rim/pattern`，土面与树根遮盖共用动态苔色。设计系统使用同一绘制和色彩算法。

旧记录没有盆器字段，或字段不合法时，继续使用原来随树形配置的盆器。冻结的 `core/v1` 模型不变，新的盆器字段由生长层单独保留；调试切换外观也不会丢失盆器。

验证：随机样本覆盖全部八款；验证不同盆器不改变树木几何与镜头、各生长阶段及回放保留配置、旧记录渲染不变、材质对比度达标。认养接口测试确认预览配置与服务端配置相同，并保留幂等保存行为。
