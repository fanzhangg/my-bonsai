# 盆景视觉方案

整体算法及数据格式见 [盆景算法当前实现](盆景算法当前实现.md)。本文单独记录视觉搭配。

日期：2026-09-16。已接入当前七款树形，外观与枝干、叶簇位置及随机种子独立。

| 方案 | 叶形 | 叶色（暗 → 亮） | 树干与根 | 背景 |
|---|---|---|---|---|
| 原色 | 随树种 | 原有分树种绿色 | 原木棕 `#6a5b48` | 暖纸白 `#faf9f3` |
| 春芽 | 圆叶 | `#2f654e` → `#a5c991` | 深胡桃 `#514336` | 浅苔绿 `#e9f0e5` |
| 枫红 | 掌状叶 | `#682e38` → `#dd8270` | 炭灰 `#4c5552` | 淡藕粉 `#f3e8e4` |
| 金秋 | 扇形叶 | `#8b692d` → `#e8cc7d` | 深胡桃 `#514336` | 暖砂色 `#efe3c9` |
| 青雾 | 细长叶 | `#48655f` → `#aec0ae` | 赤褐 `#885b49` | 雾灰蓝 `#e4ebeb` |
| 月夜 | 针叶束 | `#365c65` → `#b0c9c4` | 灰白木 `#b0a793` | 深夜蓝 `#24323b` |

叶片使用真实不同的 SVG 轮廓：圆叶与椭圆叶使用不同比例，细长叶为收尖曲线，掌状叶为多裂轮廓，扇形叶为展开的弧面，针叶由细线成束组成。保留现有叶簇体积和成组明暗，避免退回散点叶片。配色方案是美术实验，不代表松柏会自然长出枫叶或银杏叶。

“单独搭配”提供随树种、圆叶、椭圆叶、细长叶、掌状叶、扇形叶、针叶束、短鳞叶共八个选项，以及六组叶色、五种树干颜色和六种背景。树干和根同步换色，不添加中心高光线。深色背景下的单色轮廓改用浅灰绿以保持可见性。

背景只应用于盆景画面，不改变操作界面；SVG 自带背景，候选缩略图也保留各自颜色。盆器沿用款式原有配色。对照固定树形、种子与画幅，只改变外观。

实现位于 `prototype/appearance.mjs` 和 `prototype/canopy.mjs`。配置新增 `appearance: { shape, foliage, bark, background }`，保存候选、重新读取和导出时均保留。旧配置缺少外观字段时使用原色；外观变化不会改写已有候选。

测试覆盖所有七款树形与六套搭配，验证枝干、叶簇位置和画幅不变，外观配置可完整重放，叶形输出不同，无效外观选项回退默认值。
