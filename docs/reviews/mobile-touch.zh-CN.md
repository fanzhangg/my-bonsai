# 手机触屏交互审核

首页与植物详情页使用固定视口，普通场景禁止整页平移、回弹和文字选择，保留双指缩放。作弊模式保留页面滚动，输入框仍允许选择和编辑文字。

## 修复的边界情况

- 点按拿起剪刀后，在树上滑动选择旁支时，画布禁止浏览器接管平移手势，避免触发 `pointercancel`。
- 工具只响应主触点；其他手指的松开、取消或捕获丢失不会放回正在操作的工具。
- 工具操作期间，暂停的小访客不再拦截树上的点选。
- 工具归位坐标避让安全区域，并在归位动画结束时重新读取屏幕尺寸，避免旋转后停在旧坐标。
- 手机实测反馈后，将工具透明触摸区域扩大为 112×112，保持图标大小，工具上移并拉开间距。关闭工具的浏览器点击高亮，保留键盘焦点提示；Open-Meteo 链接移至左下角，与工具区域分开。
- 长按外接键盘的空格或回车不会反复拿起、放回水壶。

## 验证范围

在本地独立 JSON 存储上使用 Chromium 149 的触屏模拟，检查 320×568、390×844 和 844×390 三种视口，并查看截图。安全区域通过覆盖工具层 padding 模拟，未使用真实设备的刘海或底部手势区域。

触屏检查包含认领、点按拿起后滑动剪枝、拖动浇水、第二根手指接触同一工具、取消操作、旋转时取消、页面滑动限制和作弊表单。实际发送剪枝与浇水请求并检查本地保存结果。

后续补测强制显示天气署名链接（离线天气默认不显示），在上述三个尺寸及模拟安全区域下检查链接与工具不重叠，并从两个工具的四边和斜角触发真实触摸事件。核对拿起状态、透明点击高亮和背景，查看链接显示时的截图。

正常动画模式另检查长按与取消、剪枝保存失败后恢复、浇水失败后重试且不重复入账、认领后的前进后退，以及访客、复制失败提示、小院入口。失败重试和部分导航使用浏览器鼠标点击补查事件逻辑；触屏模拟不能代表所有手机浏览器的原生点击行为。

`tests/pruning-interaction.test.mjs` 与 `tests/watering-interaction.test.mjs` 覆盖主触点归属、取消、焦点/可见性中断、键盘重复和安全区域坐标。完整测试通过后仍应以真实 iOS Safari、Android Chrome 检查原生长按菜单、浏览器工具栏收缩和双指缩放；本次未做真机或生产数据库验证。
