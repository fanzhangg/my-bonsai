# 修叶体验审核与改进

2026-09-18 · 本地待 review，未推送。

目标是让用户用逐片落刀完成自由造型，并能持续养护自己的作品。沿用两套独立工具、整层选择、极简界面、即时落刀和每次一片的节奏；不增加目标形状菜单、高亮或停留确认。

## 本轮发现与改进

| 问题 | 对体验的影响 | 已实现的改进 |
| --- | --- | --- |
| 命中范围是叶片中心附近的圆，未随叶形变化 | 刀尖放在叶缘或针尖上可能剪不到 | 渲染与命中共用叶形，支持旋转、针叶束、展开中的小叶；实际命中优先，重叠按画面前后顺序剪 |
| 部分生长缩放只发生在 SVG 外层 | 小叶显示位置与命中位置可能不一致 | 几何位置和尺寸由同一份叶片数据生成，剪刀、掉落动画、辅助底图一致 |
| 实心准星遮挡微小叶片 | 精修凹口时难以看清落刀点 | 改为空心准星和细小中心点，保留明确瞄准位置 |
| 空剪会退出选层 | 微调时容易被打断 | 冠内空剪保留选择；键盘支持 Shift 加方向键半像素微调 |

## 趣味性与真实感的取舍

每次合剪只带走一片完整叶子或一小束针叶，并有短暂飘落。快速扫过不会排队补剪，停住不会自动挖深；修得更深需要用户继续操作。清晰的“落刀—掉叶—局部轮廓变化”反馈服务于自由造型。

形状仍由局部、平滑的树冠曲线管理，避免一片叶子掉落后整层失去结构。辅助底图只连接实际互相覆盖的叶片，边缘始终在叶片下面；剪空后不留下实心色块，也不自动补回无法剪掉的装饰叶。枝干继续由剪枝玩法处理。

生长先表现为小叶补齐，再表现为各方向略有不同的外扩。保留主形状，留出少量需要修整的新梢感。随机性可重放，不会因刷新页面改变作品。

- 使用真实逐片 `snipAt` 操作剪出爱心，检查中央凹口、双圆瓣和底尖。
- 检查 24、96、480 和 8760 生物小时后的爱心凹口保留、叶量恢复、局部随机变化和上限。
- 对生长后的树再次修剪，比较编辑器与保存重放的轮廓参数和每片存活叶子的坐标，确保保存不跳形。
- 检查冠内空剪、取消、保存失败、暂停落刀、七种树形剪空及枝干不变。

## 与稀有花叶版本整合

整合 `b2d2731` 时解决共用渲染器冲突，保留稀有配色、盆器配色和樱花/丁香/四叶草造型。花叶的渲染、命中与外缘检测复用同一组花瓣曲线；逐片修剪及新叶生长保持原有造型和花蕊。补充三类花叶的栅格命中、辅助底图覆盖、保存重放及生长验证。此兼容改动是在此前修叶 review 后新增，按仓库流程须再次 review 后才推送。

## 工具造型与节奏调整

- 连续修叶间隔由 320ms 缩短到 200ms（上限约每秒 5 次），合剪动画同步缩短。每次仍只剪一片，停住和松手不补剪。
- 准星必须在选中树冠当前可见外缘的 6px 范围内才能落刀，边缘内外均可；深入冠内、离开树冠或远离边缘都不剪，也不远距离吸附。即使一片叶子属于外缘，准星也必须靠近它实际露在轮廓上的部分。按整层存活叶片判断外缘，每剪一片重新计算，露出的下一层才能继续剪。保留凹口，不用凸包抹平爱心和猫耳；不会剪到其他层，也不会一次剪掉整团。
- 剪枝剪采用较短、较宽的刀头，靠近刀轴的大蝴蝶形握环；修叶剪采用窄尖刀头、细长柄和较小椭圆握环。刀轴、柄长、刃宽及开合动画一起区分，而非只换颜色。
- 修叶准星继续对准刀尖闭合位置；两把剪刀绕真实刀轴开合。主页面与设计系统页使用相同剪枝剪图形。

造型依据：制造商 [Wazakura 传统盆栽剪](https://wazakurajapan.com/products/wazakura-traditional-bonsai-scissors)展示靠近刀片的大蝴蝶握环；[Wazakura 长柄精修剪使用说明](https://wazakurajapan.com/blogs/user-guide/1013)说明细长结构用于叶、芽及细枝精修，[Niwaki 的 Kaneshin 精修剪](https://www.niwaki.com/us/kaneshin-bonsai-trimming-scissors/)说明长细柄有助于伸入枝叶深处。真实工具用途有重叠，本游戏按两种操作任务选择有明显差异的代表造型。
