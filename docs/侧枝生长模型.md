# 侧枝生长模型：真柏原型

> 已撤回：用户否决本轮视觉效果，相关实现和测试已移除。以下仅为实验记录，不代表当前原型。

设计目标：老枝通常更长、更粗、拥有更多下级枝，属性由发育历史产生；不能把“老枝必然更繁密”当作生物定律。真实树形还受光照、空间与内部调节影响。参考 [Self-organizing tree models for image synthesis](https://algorithmicbotany.org/papers/selforg.sig2009.html)。本文实现是受该思路启发的简化插画模型，没有复现论文完整算法。

## 已实现

- 保留已审阅主干与六条可剪主侧枝的身份、附着位置及主要出枝方向。按主干段形成次序推导主侧枝出生轮次，低位枝先出生；这是本原型的发育假设，实际树木也可能后期在低位萌芽。
- 每轮按统一规则积累伸长量。活力只有种子决定的小幅变化；已有子枝共享资源，使继续伸长和新芽激活受到限制。
- 枝轴长过统一节间尺度后留下芽位，芽等待至少两轮、且离末梢足够远才可能激活。次枝的出生时间来自芽的实际激活，而非按枝条编号指定。
- 每轮积累截面积代理量，粗度取其平方根，并受父枝连接处粗度约束。模型不是碳收支或木材力学模拟。
- 同一出枝规则作用于所有轴；以三阶为风格化上限。旧版每枝固定两条承叶枝、每条固定一条末级枝，以及按内外枝编号指定长短粗细的代码已移除。
- 从父枝曲线真实芽位开始，初始切线顺接，随后渐渐抬升。原树冠色组与叶簇尺寸保留，叶簇分配到生成的支撑枝端，包括主枝末梢。

## 范围与限制

14 轮是原型发育时间单位，不等于真实年份。统一伸长率、节间范围、等待期、层级上限仍是模型参数；它们作用于所有枝条，而非逐枝预设属性。

本轮用历史迭代生成供 Design System 审阅的成熟骨架。应用现有成长动画仍沿用原流程，没有将“生长 24 小时”改成新的逐芽发育时钟。再生仍用现有剪枝机制，未声称完成剪后资源再分配或真实光照模拟。低位老枝是否过密、末端是否过粗仍需视觉验收。

## 验证

相同种子重建一致；同一轴延长模拟时间后，长度、面积及下级枝数增加，既有芽出生时间不变；节点接枝连续，叶簇跟随支撑端；剪主枝只移除该枝族，幸存枝不重排，撤销可恢复。全局设计参数与生理规律分开记录。
