# 一盆树

新认养盆栽会随机配备八款设计盆器之一，盆形、颜色和花纹随盆栽保存。预览、认养后与再次打开链接保持一致；旧盆栽保留原盆器。见 [随机认养盆器](docs/随机认养盆器.md)。

手机优先的 Prototype：首页每次刷新出现随机幼苗，一键认领眼前这棵树；通过固定链接回来观察生长，打开时自动快速回放。认养后可以拖动右下角剪刀，松手剪除旁支，主干始终保留。

沿用七款树形与六套视觉方案；当前不提供命名或参与者。基础实现见 [应用 MVP 实现](docs/应用MVP实现.md)，新增剪枝行为见 [剪枝交互实现](docs/剪枝交互实现.md)。

首页左上角的网格图标打开 `/gallery`，入口仅在首页显示。小院展示最多 200 盆已认领且有访问或操作记录的盆栽图片，使用各树配色对应的背景，无标题、文字或边框，仅在左上角保留返回首页的箭头图标；按最近活跃时间（互动、访问中较晚的一次）倒序。图片按当前生长和剪枝状态绘制，点击即可探望。

每批只读取 24 盆，滚动接近底部时通过游标加载下一批，累计到 200 盆即停止。浏览器只绘制视口附近的 SVG，远离视口的图形释放，返回时重新绘制；逐盆让出主线程，避免一整批绘制阻塞操作。翻页期间排名发生变化的树会在刷新后重新排序。`activity.mjs` 中的 `GALLERY_LIMIT` 和 `GALLERY_PAGE_SIZE` 控制总上限与每批数量；本地测试不代表生产数据库和移动设备的延迟。

成功剪枝、保存作弊修改记录服务器实际互动时间；打开树页面（包括认领后继续观看）、重新切回可见页面记录访问时间。定时同步、加载 Gallery 和缩略图不计访问，也不修改树的版本。现有记录以历史剪枝时间兼容，过去未记录的访问无法补回。当前没有账号或所有者身份，互动指树页面上的成功操作。PostgreSQL 和本地 JSON 均支持保存活动记录和查询 Gallery。

## 本地运行

需要 Node.js 22.9+，推荐 24。

```sh
npm ci
npm start
```

打开 [一盆树](http://127.0.0.1:4173/)。默认使用 `data/trees.json` 持久保存本地盆栽。

```sh
npm test
```

## Render + Neon

仓库包含 `render.yaml`。在 Render 设置 Neon 的 `DATABASE_URL` 后部署。生产模式强制使用 PostgreSQL；未配置数据库不会启动。本地可复制 `.env.example` 为 `.env` 后填写连接串，启动命令会自动读取。

当前尚未连接真实 Neon 或部署 Render；本地功能可直接体验。

## 作弊模式与算法研究

- [设计系统 · 树形谱系](http://127.0.0.1:4173/design-system.html#trees)：新版粗干收分与差异化冠形，可切换旧版、裸枝、剪影及五组样本。见 [盆景形态研究与改进](docs/盆景形态研究与改进.md)。

在盆栽链接末尾加 `?cheat=1`（兼容 `?debug=1`），进入作弊模式：调整时间、树形、外观、种子或剪枝后，点击“保存到这棵树”即可持久保存，刷新或退出模式后仍然保留，并从保存后的年龄继续生长。首页调整后的样本会在认领时一起保存。更换树形或种子会清空旧剪枝，单独换外观会保留剪枝；“重新载入已保存状态”可丢弃未保存的修改。天气和当地时刻仅供预览。

- [树冠与视觉研究](http://127.0.0.1:4173/research.html)：原候选记录保留。
- [旧版选样](http://127.0.0.1:4173/selection-v1.html) / [旧剪枝工作台](http://127.0.0.1:4173/workbench.html)。
- [树冠算法实现记录](docs/盆景算法当前实现.md) / [视觉方案](docs/盆景视觉方案.md)。
- [原产品设计](docs/一盆树-MVP设计文档.md)：首版应用范围以最新实现文档为准。

`prototype/core/v1/` 是应用冻结的算法依赖；当前应用由 `growth.mjs` 处理生长及已保存的剪枝，`life.mjs` 保留旧实验模型。`server.mjs` 提供应用和 API，`storage.mjs` 提供 PostgreSQL / 单进程本地存储。

## 天气与时间

首页和领养页共用当地时间渐变及实时天气动画；需要浏览器定位授权，位置不可用时回退到设备时间。Debug 可单独预览天气和时刻，详见 [天气与时间背景](docs/天气与时间背景.md)。
